# 最小SPIプロトコル1（RTL試作）

既存I2C v2とは別の、基板ピン未確定の試作用インターフェース。
Pico側の実SPIドライバー・設定ローダーは未実装。
`tools/protocol.py`はパケット生成と応答検査だけを行い、ハードウェアへアクセスしない。

## 電送

SPI mode 0、MSB first、最大1 MHz。音源側16 MHzで2段同期して受信する。
推奨CS setup／hold各1 µs以上、CS間2 µs以上。
CSがlowの間にちょうど64 bitを送り、CSがhighへ戻ったときだけ命令を確定する。
短すぎる／長すぎるフレームを受理しない。MISOはCS highでhigh-Z。

| byte | 命令 |
| --- | --- |
| 0 | opcode |
| 1 | YMレジスタ（未使用命令では0） |
| 2 | 値（未使用命令では0） |
| 3～6 | STARTからの相対µs、32 bit big endian（未使用命令では0） |
| 7 | 先頭7 bytesのCRC-8、poly=0x07、init=0、非反転、xorout=0 |

最大時刻は4,294,967,295 µs（約71分35秒）。時刻の折返しは停止要因。
WYM1のミリ秒時刻を1,000倍して投入する想定。単一4 MHz・通常分周のYM2203だけを対象とする。

| opcode | 意味 |
| --- | --- |
| `00 READ` | 状態取得のみ。再生・リースに影響しない |
| `10 BEGIN` | 再生を止め、両FIFO・時刻・fault・SEALをクリア。自動再生しない |
| `01 ENQUEUE` | レジスタ／値／時刻を1件投入。時刻は非減少。0x2D～0x2Fは拒否 |
| `02 START` | 先頭から時刻0で実行。FIFO非空・音声prime済み・faultなしが必要 |
| `03 KEEP` | 再生中の1秒リースを更新 |
| `04 STOP` | 再生と両FIFOを停止・破棄。faultは保持する |
| `05 SEAL` | 時刻欄に正常終了時刻を指定し、以後のENQUEUEを禁止 |

再生中に受理したENQUEUE／SEALもリースを更新する。
SEAL時刻は最終イベント時刻以上、かつ過去ではいけない。
BUSY待ちやキーオフ後の減衰を含めるため、終端には余裕を置く。WYM1の既存periodを使える。
未SEALでイベントが1 ms以上枯渇すると停止する。満杯時に書き込まず、応答のfree_slotsで補充量を調整する。

## 応答とACK

MISOの8 bytesは**CS開始時点**のスナップショットであり、同時に送った命令の実行結果ではない。

| byte | 応答 |
| --- | --- |
| 0～1 | `4A 01`（J、protocol 1） |
| 2 | flags：bit0 ready、bit1 running、bit2 fault、bit3 audio_primed、bit4 sealed |
| 3 | error code |
| 4～5 | 空きイベント数、16 bit big endian（最大257） |
| 6 | 処理した制御命令カウンター、8 bitで周回。READは増やさない |
| 7 | 先頭7 bytesのCRC-8 |

命令送信後はREADで新しいACKとfaultを確認する。エラーを伴う命令処理でもACKが増える場合があるので、
ACKだけで成功と判断しない。クリア中・既存fault中の通常命令は実行せずACKも増やさない。

この最小版は要求IDによる重複除去を持たない。**応答不明のENQUEUEを自動再送しない。**
CRC不一致やACK不明時には停止を確認し、BEGINから全セッションを再構築する。

## 標準シーケンス

1. BEGIN、READでreadyとaudio_primedを待つ。両フラグが立つまではSTARTしない。
2. 先頭のイベントを投入する。短い曲なら全件投入・SEALも先にできる。
3. START。free_slotsを確認して将来のイベントを補充し、KEEPを1秒より十分短い間隔で送る。
4. 最後の投入後にSEAL。running=0、fault=0、ゲート閉が正常終了。
5. 次の曲、STOP後、異常復帰はいずれもBEGINから開始する。

STOPや復帰時に旧イベント・旧PCM・旧再生要求を自動再利用しない。
BEGINは再生中でも全停止するため、状態照会の代用にしない。

## エラー

| code | 内容 |
| --- | --- |
| 1 | フレーム長／CRC異常 |
| 2 | 命令／引数／状態／終端時刻異常 |
| 3 | イベントFIFO満杯 |
| 4 | 投入順序・禁止レジスタ・SEAL後の投入等 |
| 5 | 通信リース期限切れ |
| 6 | PCM FIFO満杯 |
| 7 | PCM FIFO読出し枯渇 |
| 8 | I2Sクロックのハートビート停止 |
| 9 | 未SEALのイベント枯渇 |
| 10 | 終端時刻までにイベント／バス処理が未完 |
| 11 | µs時刻の折返し |
| 12 | BUSYによる実行妨害が1 ms継続 |

すべて消音・キュー破棄へ進む。音源クロックが停止している場合は音声側faultが先に出て、
音源側の復帰後にerrorへ反映される。複数要因が同時に成立した場合は最後に判定されたcodeが残る。
