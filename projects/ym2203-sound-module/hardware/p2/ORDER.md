# review U 発注条件

ベースT/FAB U、音源T/FAB U、編集N/FAB Uの基板を各5枚。部品は1セット、すべて自前実装する。
旧R/OのZIPや購入シートを混ぜない。UのZIP名とSHA-256は[manifest](provenance/manufacturing-manifest.json)。

シルク文字高さ1.0mm以上／線幅0.15mm以上／パッドとの間隔0.15mm。白シルクは両面出力する。
ペースト層は意図的に含めない。4層はF/In1/In2/Bの順。インピーダンス制御オプションは指定しない。
KiCadの仮の詳細積層を誤注文しないよう、Gerber JobのMaterialStackupは省略し、上表で厚さと銅厚を指定する。
これによりUSB FSのインピーダンスが保証されるわけではなく、P2実機で確認が必要。

PTH／NPTHは別ファイル。穴の統合・入替はしない。
ベースのUSB-C固定足4か所とDCジャック3か所、編集パネルの操作部8か所は**メッキ長穴**。
基板内に切欠き・開口はなく、全て長方形。Jobの外形寸法には描画線幅が加算されるため、外周線の中心が上表の寸法である。
標準ビアの一部はSMTパッド際にあり、先にはんだで処理してから手実装する。
有料のビア樹脂充填／銅蓋、SMTサービスは前提にしていない。

ZIPには銅層、マスク、シルク、外周、PTH/NPTHドリル、Gerber Jobのみを平置きし、
組立SVG・穴マップ・検査JSON等は含めない。ZIP内のCRCとSHA-256も生成時に検査する。

アップロード後は業者のCAM画面で、3枚の外形・向き・内層順・PTH/NPTHと長穴を確認する。
**業者へのアップロード、正式CAM審査、最終送料・税を含む見積、注文は未実施。**
