# review T の互換性と実装境界

外部の通信形式を変えずに、基板内部のGPIOと表示回路を変更する。Rev Cの既存HOSTプレーヤーを
Tで動かすためには、従来計画どおりP2のベース／音源分割ファームウェアが必要である。
**回路の接続契約を維持したことと、実機でHOSTが動作したことは異なる。T用ファームウェアは未実装。**

| 境界 | 維持する内容 | Tでの変更 |
|---|---|---|
| HOST | I2C0 SDA=GP20、SCL=GP21、3.3V、0x42、100kHz、protocol v2/WYM1 | 変更なし。データ形式、件数／CRC、BEGIN/UPLOAD/PLAY/KEEP/STOPの意味を維持 |
| USB | ベースUSB-C、CDC＋USB-MIDI、USB経由WYM1再生の計画 | RP2350BのUSBへ配線。USB VBUSは検出のみ、5V給電から分離 |
| 制御権 | MIDI中BEGIN拒否、I2C中Note On拒否、STOPは全体停止 | ファームウェア要件を維持 |
| 切断・リース | I2C通信断はキュー取消・全音消音。再接続／読み取りで再演奏しない | ファームウェア要件を維持。明示STOP/BEGIN/PLAYまたは新しいNote Onでのみ再開 |
| G40 | 40接点のピン番号、電源、アナログ2本、SPI／パラレル、I2S、ENABLE/ALERT | ベースR／音源Nと全ピンのネット一致を検査 |
| STOP／RESET | ベースGP23 STOP、GP19 DAC_ALLOW、GP22 LINE_ALLOW、外部RESET | 変更なし。RUNは2BのSW1から配線が必要 |
| アナログ音声 | YM3014 FM＋SSGを別々に共通ADCへ。MCU内合成後にPCM5102Aへ | DAC後段に物理ボリューム＋TPA6138A2。両ch同相の反転増幅−1倍 |
| I2S | オプション音源I2S DATA/BCK/LRCK | 音源MCU内部のみ旧GP24/25/26からGP29/30/31へ移設。G40ピンは維持 |
| 音色編集 | 3.3V SERVICE I2C GP26/27、パネルNのLCD直結・EEPROM | 変更なし。音色編集コマンドの実装は別途必要 |

GPIOの全割当は`gpio-map.csv`を参照。2Bの48GPIO中GP24/25は基板上LED用として外部には使わない。
ベース35本使用／11本予備、音源34本使用／12本予備（基板上LEDの2本を除外した数）。

USB経由のWYM1も共通の再生キュー／所有権／STOP・リース処理へ渡す。USB専用の別演奏エンジンや自動再演奏は追加しない。

## 表示の動作要件

- POWERはヒューズ後5Vから抵抗2.2kΩで直接点灯し、ファームウェアに依存しない。
- RX/TXは各1kΩを介する3.3VのアクティブLow表示。USB／HOST／音源リンクの有効データでパルス延長する。
  単なるポーリングやステータス取得を「演奏データ受信」と取り違えない。意味の分離は実装時に固定する。
- 音源側FM1..3/SSGA..Cはキーレジスタ／ミキサ設定をもとに表示する。実際のPCM振幅や無音の検出器ではない。
  FMエンベロープの自然減衰やSSG音量0で、LEDと聴感が常に一致するとは限らない。STOP、リース切れで全消灯する。
- RGBはWS2812B-V6。5V電源、SN74AHCT1G125で信号を5Vへ変換。GRB24bit、800kHz。
  1 PIO SM／1 GPIO、初期案は4命令・24bitを1 FIFOワード、1更新約30µs＋リセットLow350µs。
  値が変化した場合だけ最大20Hz、明るさ制限を使い、音声処理中の割込み禁止や送信完了のビジー待ちはしない。
  色の割当やCPU負荷は未実装・未測定。WS2812はMCUリセット後も最後の色を保持し得るため、安全状態の保証には使わない。

## ミュートの順序

通常停止／リース／制御権破棄時は、まずDAC_ALLOWとLINE_ALLOWを落とす。
既存UMUTEのAND出力`DAC_XSMT`がDACのXSMTとアンプMUTE_Nを同時にLowへする。
キューと発音状態を取消し、音源ENABLEを落とす。新しい演奏開始時は無音データを準備してから許可する。
物理STOPはMCUへの入力であり、独立ウォッチドッグを新設した設計ではない。起動時の既存プルダウンは維持する。

## 実機で必要な確認

既存HOSTの全曲／件数CRC、STOP・通信断・読み取りだけの再接続、MIDIとの制御権切替、USB切断、
10分待機、パネル編集、LED更新中の音切れ、ヘッドフォンとLINE両負荷での全音消音を確認する。
