# review Bの寸法候補と現物確認

review Aの配置合格をBへ引き継がない。PCB配線とDRCはまだ行っていない。
UNO32接点はP2ベースreview Iの配置を維持し、ICSPヘッダーへは嵌合しない。
元のUNO接点座標は[geometry/uno.json](geometry/uno.json)、原点と候補外形は[design-verification.json](design-verification.json)。

- 候補外形76×100mm、ベース上原点(10,10)mm。音源基板の開始x=90mmに対してXY間隔7mm。
  コネクタやシールドのはみ出しは別途確認する。
- LCD基板32×43.72mmを横向き44×33mmの包絡で配置する案。四隅固定、配線は8本。
  液晶背面とリード抵抗の重なりを避けるかスペーサーで離す。まだ固定穴位置はPCBへ採用していない。
- つまみ外径16mm、中心間隔19mm候補で名目隙間3mm。指の操作性と基板端からの距離を現物で確認する。
  RK09の長い軸とS-42の差込み深さにより、他ボタンより高くなる。必要ならパネル高さや軸長を変更する。
- encoderは表面実装品。ED2独自footprintはメーカー図をもとに作成した検討用。
  A/B/Cと回転方向、位置決め穴、付属shaft、押込み高さを実物・印刷1:1で照合するまで製造に使わない。
- EEPROM DIP8とリード抵抗は表面側へ置く。裏面リードを3mm以下へ切り、PGA2350やベース部品へ接触させない。
  表面側でもLCD裏との干渉があるため、部品位置を確定する必要がある。
- UNOの最小基板面間10.5mm、下側部品5mm以下・裏面3mm以下というAの仮定を再評価する。
  Bの部品干渉について2.5mmの余裕を確認済みとは扱わない。ソケット型番と差込み長を確定して再計算する。
- 裏面ICSP keepout、ベースSTOPの被覆、シールドSTOPへの代替経路、ベースTESTへのアクセス、
  Si5351AクロックDIPのアクセス窓は引き続き要確認。窓を設ける場合は銅箔・部品配置とも避ける。

標準RK09K footprintをRK09Dの電気端子・金属脚候補として使う。筐体と軸の相違を現物で照合する。
TVDP01も6mm標準footprint候補で、実端子間隔とスイッチ高さを確認する。
自作の抵抗・コンデンサー形状やUNO形状は原図の画像を転載せず座標から作成した。
