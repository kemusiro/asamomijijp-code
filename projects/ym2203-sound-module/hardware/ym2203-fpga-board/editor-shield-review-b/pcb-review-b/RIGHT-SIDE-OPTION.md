# ベース操作子を音源基板側へ移す比較案

2026-11-18。DIP・STOP・TESTを右側へまとめる案は、装着したまま操作できる点で妥当。
音源基板の下へ移すと再び覆われるため、音源基板の外側に操作用スペースを設ける。
今回の「ベース配置維持・矩形シールド」とは別の候補として扱う。

現状はベース幅194mm、音源基板右端x190mmで、外側の余白は4mmしかない。
右外側へ3操作子を並べるには拡幅が分かりやすい。例として幅220×高さ142mmなら、
DIP原点(203,50)、STOP(203,82)、TEST(203,105)mmの候補で、
現ベース部品と音源基板の包絡に重ならず、右端の余裕も確保できる。
[寸法検討](right-side-option.json)はnative footprintの外形だけを照合したもの。
ベースを26mm拡幅する案であり、まだ部品移動・再配線・DRC・支持点/ケース/操作性の確認はしていない。

GPIO/netを保った位置変更なら、HOSTのI2C ABIやUSB-MIDIの仕様変更は不要。
STOPは全音源共通の操作なので、音源基板へ載せ替えずベース側に残す。
配線長が延びるため入力のpull-up/debounce・GND・音声/クロックとの並走を新配置で確認する。
幅を維持する場合は、音源基板上側のPGA・USB・電源・LED等を含めた再配置の検討が必要。

**現時点でベースIは変更していない。** この別案を今回のシールドDRC0で検証済みとは扱わない。
