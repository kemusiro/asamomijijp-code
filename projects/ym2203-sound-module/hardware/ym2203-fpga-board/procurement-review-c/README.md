## 購入前に解消する項目

1. **C01：100nF 28個のGRM21BR71H104KA01L、C09：2.2nF 2個のCC0805JRNPO9BN222に生産終了表示。**
   C01には同じ公称容量/耐圧/温度特性/0805のKEMET C0805C104K5RACTUを候補記録。
   正式な寸法・高さ・使用箇所照合と、新BOMへの採用は未実施。C09の代替選定も残る。
2. U01 Si5351A、U07 LDO、U08/U14のTIロジック、D01、R04/R05、C06などは調査した販売ページで在庫0。
   同一MPNのCT/包装違いや別の正規購入先を確認する。別メーカーや似た品番へ無条件変更しない。
3. **販売単位未確定18行**：M03、X01、F01、L01、R05/R06/R07/R14/R17、C01/C08/C09/C11、H05/H06、E09/E10/E11。
   M03はYM2203Cの手持ち/信頼できる供給確認。H05は嵌合測定後の厚さ決定。
   H06はSSW対応PK-01-06が候補だが、販売1単位が単独キーか6個wheelか未確定。
4. E09〜E11は自作ハーネスの部材へ分割して具体化する必要がある。
   E13の秋月5V2Aアダプター候補はDCプラグなのでJPOWERに直結できず、電源ハーネスの変換も必要。
   公称5Vを全条件5.0〜5.1V保証と扱わない。E12の100円ケーブルはPC側にType-Aがある場合の候補。
5. BのF01 package欄にIhold1.5A、note欄に2Aの不一致が残っている。
   指定MF-MSMF200/16X-2は2A hold@23℃。保存版Bを改変せず、次の購入表改訂時に注記を訂正する。

候補の詳細は[candidates.json](candidates.json)。候補の追加はCAD・GPIO・40接点・UNO配列・HOST API・USB-MIDI・STOP/leaseの変更ではない。
現物嵌合・P2の通電/音声/USB受入は未実施で、Rev Cの受入を流用しない。
