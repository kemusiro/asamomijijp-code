# review Kの2層配線・電源・評価条件

Kのnative PCBと検査結果が対象。J/Iの4層の連続GND面・電源補助面を持つという説明をKへ流用しない。
F.Cu/B.Cuに信号・電源・共通GNDを配置し、表裏GNDを複数のビアで接続する。GNDの意図的な分離・スリットは設けない。
フィル後の島・帰路は専用平面のある4層版より複雑になる。DRCの接続合格は帰路の低インピーダンスを保証しない。

## 電源

H/Jと同じ回路・部品・負荷予算。PGA 3V3は265/300mA、AUX 3V3は350/500mA、音源5Vは350/500mAの設計境界。
入力の設計見込み1.240A、供給候補5.1V/2Aは従来条件を維持する。UNO外部負荷を無制限に供給する仕様ではない。
AUX LDOの境界損失は約0.718W。表面の出力銅箔を確保するが、内層の放熱・電源補助面はない。
入力5V・5V配電にはUSB主配線の範囲（y約6.3～14.2mm）を避けて表面補助銅箔を追加した。
同じ負荷容量を2層版の実測合格として扱わず、入力から各負荷端までの電圧降下とLDO・配線・ソケットの温度を確認する。

GNDは表裏で接続し、ADC/DACのデカップリング帰路を接続する。密集部でサーマルスポークが成立しないGND接点は局所的に直結する。
これらのスルーホール接点は手ハンダ時に熱を逃がしやすいので、適切なコテ容量・予熱を用いる。
電源線幅・ビア数・フィルの実測値は[routing-review.json](routing-review.json)とnative CADを参照。

## USB・音声・クロック

USB回路・部品値・端子位置は維持するが、2層の配線形状はJと異なる。
D+は総配線長34.5088mm・ビア0、D−は31.8310mm・ビア4（枝を含む合計、電気長ではない）。
D+/D−の長い区間を表面側へまとめ、D−のMCU引出しとコネクタ近傍だけで裏面へ移る。総分岐長やビア数は遅延・差動インピーダンスの測定値ではない。
板厚1.6mm・一般的な2層FR-4のまま、4層版の配線幅を90Ω保証として扱わない。メーカーのstackup指定とインピーダンス計算、
USB CDC/MIDIの接続・切断・連続通信、実機の音切れ・ノイズを確認する。2層比較案の主な評価課題である。

音源側のYM FM受信Y_SD/Y_SHは従来の短い表面経路を維持する。SSGアナログ出力と5Vレベル変換の回路も維持する。
G40のFM/I2S信号、ベースのADC/DAC信号は接続照合するが、配線の分岐・並走・層遷移があるので、クロック波形、
FM受信エラー、I2S連続性、音声のノイズ床を実測して4層主案と比較する。
Si5351Aの周波数範囲、DIP設定、STOP時のクロック・reset順序はHの契約を変更しない。

## 実機比較で確認する項目

- 同じ音源・電源・ケーブルで、Jベース4層＋K音源2層とKベース2層＋K音源2層を比較する。
- 無音時と6声時のノイズ、FM/SSGバランス、ADC入力、USB接続時のノイズを確認する。
- HOSTの長時間再生、USB-MIDIとの制御権切替、STOP、lease、切断・再接続後の無音を確認する。
- 入力・PGA3V3・AUX・音源5Vの電圧と温度、ソケット・シールド・ネジ頭の干渉を確認する。

これらは実施前の評価条件。今回のCAD/DRC結果をP2 firmwareや実機の受入結果として扱わない。
