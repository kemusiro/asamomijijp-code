# C14：ADC入力コンデンサの試作選定

2026-11-19。対象は**購入ID C14＝ベースCACL/CACR各1個**。
音源基板の回路参照C14（100nF）とは別。
旧候補GRM21BR71C106KE51Lを、**Murata GRM21BZ71C106KE15L**へ置き換える。
0805/2012、10µF±10%、16V、公称寸法2.0×1.25×1.25mm（高さ最大1.45mm）。
CADは元から10µF/16V/0805なので変更しない。

採用根拠は[村田製の検索用データシート（Farnell掲載、2024-01-10）](https://www.farnell.com/datasheets/4127428.pdf)の
p2仕様とp3のDCバイアス/AC電圧曲線。図を画像化して目視確認した。
この資料は代表特性で、最新版承認仕様書ではない。メーカーPIMからの最新版取得は403で未完。
Z7の表記はX7R(Murata)、温度特性は定格50%のバイアス条件を伴うため、通常のR7と無条件に同一視しない。
資料URL・SHAと調達先は[source-records.json](source-records.json)に保存する。PDFはGitへ複製しない。

## 回路条件と選定計算

回路は入力→6.81kΩ→分圧点（10kΩで接地）→CACL/CACR→2.2kΩ→ADC。
抵抗は1%。ADC入力には470pFとBAT54Sのクランプがある。
[TI PCM186x SLAS831D](https://www.ti.com/lit/ds/symlink/pcm1863.pdf)の9.3.1に従い、ADC側DCをAVDD/2として扱う。
2.1Vrmsという音声入力振幅を、結合コンデンサのDCバイアス値として代入しない。

試作の通常給電中を、信号源DC 0～5.25V、AVDD 3.0～3.6V、信号源抵抗0～4.7kΩとして評価。
分圧率の最大は10k×1.01/(6.81k×0.99+10k×1.01)。信号源抵抗0が左側DCの上限になる。
両側の端点を評価した結合CのDC差は最大1.8Vなので、曲線読取りは2Vで見る。
ADCが未給電なら左側は約3.15Vになり得るが、これを正常音声動作の容量判定条件にはしない。
負電圧の外部DC、独立給電のホットプラグや異常入力を検証したものではない。

| 要素 | 計算に使う値 | 根拠/扱い |
| --- | ---: | --- |
| 公称容量 | 10µF | 指定品 |
| 容量公差 | 0.90 | ±10%の下側 |
| DC残存率 | 0.95 | 2V以下の代表曲線を丸めた選別値 |
| 小信号AC残存率 | 0.70 | 低AC振幅で約0.72～0.75の代表曲線を切下げ |
| 温度の設計余裕 | 0.85 | 複合条件保証ではなく選別用仮定 |
| 追加の設計余裕 | 0.95 | 経時変化の仕様値/保証ではない |

積は**4.8328875µF**。小信号ACによる容量低下を無視したDCのみの評価を避けた。
各代表曲線は別条件で測られており、掛け算は部品選択のための近似。
**4.83µFはメーカー全ロット・全温度・経時後の保証最小値ではない。実測合格とも扱わない。**
今回は個人用試作として採用し、給電後のC両端DC、20Hz付近の応答、起動時の収束を実物で確認する。
通常給電でDC差が2Vを超える場合、負DCを持つ音源を接続する場合、温度条件が変わる場合は再評価する。

ADC入力抵抗はメーカー代表20kΩ。10～40kΩは従来設計のスクリーニング範囲で保証上下限ではない。
高域側基準に対するAC結合の低域損失は、((信号源R+6.81k)||10k)+2.2k+ADC入力Rで計算する。
抵抗公差と入力Rのコーナー計算を[capacitor-screen.json](capacitor-screen.json)へ保存。
追加余裕込み4.83µFで最大コーナー周波数は約2Hz、20Hzの相対損失は約0.05dB以下。
ADC自体のデジタルHPFや絶対利得を含めた総合周波数特性ではない。
有効容量15µF以下という従来仮定の5τは4秒未満で、初回ミュート4秒案を維持する。
STOP/BEGINごとにADC給電を切り直して4秒待つ仕様にはしない。P2実装/実測はこれから。
