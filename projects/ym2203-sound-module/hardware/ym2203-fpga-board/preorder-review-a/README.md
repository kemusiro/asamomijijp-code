# 発注前部品照合 review A

2026-11-18。ベースJ・4層／音源K・2層／開口なしシールドB・2層、各5枚・部品1セットを維持する。
既存CAD・Gerber・購入表・ZIPは変更していない。今回の照合は追加の部品適合レビューであり、
以前のERC/DRC・CAMの合格を取り消すものでも、現物実装の合格を意味するものでもない。

**USB-Cコネクタの推奨ランドと現行PCBに寸法差があるため、ベース基板の発注はこの照合を解決してから行う。**
保存済みの注文一式は数量・製造形式の検証済みスナップショットで、部品適合の最終承認済みデータではない。

## 1. USB-C：購入品の図面に合わせた局所修正を次の設計作業とする

対象はBOM J10／ベースJUSB、HRO TYPE-C-31-M-12。
販売先を型番検索だけでなく[LCSC C165948](https://www.lcsc.com/product-detail/USB-Connectors_Korean-Hroparts-Elec-TYPE-C-31-M-12_C165948.html)まで具体化した。
そこからリンクされた[HROメーカー図面](https://datasheet.lcsc.com/datasheet/pdf/9e56b777c022540fcce7c7f67825f55e.pdf?productCode=C165948)は
2020-12-08版、単位mm、推奨ランド図を持つ。PNGへ描画し、穴・長穴・パッド寸法を目視照合した。
PCB側はKiCad 10.0.5のpcbnewで保存済みフットプリントの実寸を読み取った。

| 対象 | 現行ベースJ | 購入先掲載メーカー推奨ランド |
| --- | ---: | ---: |
| 位置決めNPTH径 | 0.65 | 0.60 |
| 信号パッド長 | 1.45 | 1.14（穴基準から0.50～1.64） |
| GND外端パッド中心の左右間隔 | 6.50 | 6.40 |
| VBUSパッド中心の左右間隔 | 4.90 | 4.80 |
| 奥側シェル長穴の幅×全長 | 0.60×1.20 | 0.60×1.40 |
| 奥側シェル銅箔の幅×全長 | 1.00×1.60 | 0.90×1.70 |
| 手前側シェル銅箔の幅×全長 | 1.00×2.10 | 0.90×2.00 |

同じ型番でも図面版と既存ライブラリが一致するとは限らない。寸法差だけで実装不能と断定しないが、
実物未確認のまま「適合済み」として発注しない。前後の呼称はUSB開口部に近い側を手前とする。
現行BOMのnoteにある「12接点」は誤記で、購入先とメーカーは16接点品。購入表更新時の修正対象とする。

対応は**現物と一致するメーカー版を調達指定し、その推奨ランド・固定脚・基板端位置に合わせる局所修正**を第一候補とする。
USBのD+/D−、CC、VBUS分離・検出、I2C/UNO/G40の配線仕様・GPIOは維持する。
Jを上書きせず次版CADを作り、USB近傍の再配線、ERC/DRC、回路図差分、CAMを再検査して新Gerberを出す。
既存J/K/Bの他の基板を無条件に変更する理由はない。

## 2. MCU独立ソケット：外形を確認、嵌合は現物で確定

J02はMill-Max 0300-2-15-15-47-27-10-0、合計128個。
取得できた[メーカー旧カタログp177](https://media.digikey.com/pdf/Data%20Sheets/Mill%20Max%20PDFs/Pin_Receptacles_FOR%200%2C64-0%2C94.pdf)は
0.64mm角ピン対応、0300の最小実装穴1.07mm、胴部径1.57mm、下側端子径1.02mmを示す。
0300-2の下側端子長Aは4.75mm、全体の上側寸法は5.33mm。
現PCBの穴1.20mm、ピッチ2.54mmは名目上整合する。最新の購入品図面・仕上がり穴公差はなお確認する。

1.6mm基板で端子が肩まで入れば裏面の端子突出は名目4.75−1.60=3.15mm。
従来の「音源裏面は、はんだ込み4mm以下」ははんだ盛りと実部品公差を含む組立条件として残す。
胴部1.57mmを1.20mm穴に押し込む構造ではない。閉じた受け筒を切って高さを合わせない。

[秋月100167 PH-1x40SG](https://akizukidenshi.com/catalog/g/g100167/)は樹脂高さ2.5mm、接触部6.1mm、基板側リード3mm。
MCU基板下面に樹脂を置く通常の取り付けなら、MCU下面から先端まで2.5+6.1=8.6mm。
MCU下面高さ9.5mm、ソケット口高さ5.33mmを名目とした挿入は8.6−(9.5−5.33)=4.43mm。
樹脂を省略・移動すればこの計算は使えない。9.5mmを固定したままピンだけ短くしない。
最初に各MCUの角部を含む少数端子で底付き・保持力・四辺の樹脂干渉・はんだ突出を試す。
4.43mmは幾何計算であり、メーカーの保証挿入量や現物の底付き余裕を確定した値ではない。

## 3. ADC入力AC結合：容量候補を発注確定にしない

BOM C14はベースのCACL/CACR（2個）を指す。音源基板の回路参照C14（100nF）とは別。
既存候補GRM21BR71C106KE51Lについて、今回メーカーの正確な品番とDCバイアス特性を確認できなかった。
流通サイトに型番があることだけで確定せず、既存BOMの「候補」表示を維持する。

[TI PCM186xデータシートSLAS831D](https://www.ti.com/lit/ds/symlink/pcm1863.pdf)の9.3.1は
ADC入力がAVDD/2へバイアスされることを示す。AVDD=3.3V、信号源側DC=0Vなら結合Cの定常バイアスは約1.65V。
信号源側DCや起動過渡が加わる場合は、この値を最大電圧とみなさない。

名目10uF、±10%公差、温度で−15%を別々に見込む一次スクリーニングでは、
有効4.7uFのためDCバイアスによる残存比が4.7/(10×0.9×0.85)=約61.44%以上必要。
これらを独立に掛ける計算は選別用の仮定で、メーカーの複合条件保証ではない。
最終的には動作範囲・AC振幅・経時変化も含む資料か測定で判断する。

村田の[公開品番リスト](https://www.murata.com/-/media/webrenewal/tool/library/common-pdf/dynamic-model/component-list-d-mlcc-2608.ashx?cvid=20261106010000000000&la=en)には
GRM21BZ71C106KE15（10uF/16V、0805、±10%）がある。代替の調査候補にはなるが、
Z7とR7の温度規格を同一視せず、DC曲線・保証条件・在庫まで照合してから採用する。
今回この品へBOMを変更したり、有効容量の合格を付けたりしていない。

## 進め方

1. USB-Cの購入品とメーカー図面版を固定し、ベース次版の局所修正・再DRC/CAMを行う。
2. CACL/CACRの正確な型番・有効容量、MCUソケットの最新図面と少数現物嵌合を確定する。
3. 指定Samtecの完全嵌合高さに支柱を合わせ、G40 KEY6、UNO/LCDの裏面リード条件を確認する。
4. 変更後のGerber／購入表／ZIPへ更新し、基板各5枚・部品1セットで発注条件を再照合する。

HOST API・USB-MIDI・STOP/leaseは維持要件。P2ファームウェアと実機試験は未完のまま。
今回価格や送料の全面再見積、PCB発注、部品購入、commit/pushは行っていない。
機能追加や保護回路の増設を理由にしていない。発注前に未確認だった部品適合の残りを具体化したもの。

## 確認記録

[audit.json](audit.json)は元ファイルSHA、JUSBの実寸、ソケットの算術を保存する。
[audit.py](tools/audit.py)はKiCadのPythonで読み取りだけ行い、基板を保存しない。
メーカー図面の数値は目視転記で、PDFを自動的に寸法解釈した検査ではない。
取得PDFはGitへ複製せず、URLとSHAだけを[source-records.json](source-records.json)へ記録した。

プロジェクトルートから、KiCadのpcbnewが利用できるPythonで実行する。

```sh
python3 hardware/ym2203-fpga-board/preorder-review-a/tools/audit.py
python3 hardware/ym2203-fpga-board/primary-order-5pcb-1set/tools/verify.py
git diff --check
```

監査コマンドのPASSは「寸法差を再現できた・元データを保持した」という意味で、発注承認ではない。
