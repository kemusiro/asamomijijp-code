# review DからEへ移す部品と省く部品

数量は構成単位の比較。Eの回路図/BOM/見積は未作成で、Dの購入表はD専用として保存する。

| ブロック | D | E主案 | 影響 |
| --- | --- | --- | --- |
| PGA2350 | ベース1 | 同じ1 | UNO/USB/HOST/操作を維持 |
| Core2350B0 | 各音源に前提 | YM等のデジタルdecode時のみ | PSG/発声/ラジオ/SN76477へ必須化しない |
| PCM1863 ADC | YM音源側1 | ベース側共通1 | アナログカード毎のADC実装不要 |
| SSG→ADC | 3声をADC内部mix | 音源側抵抗mix→共通ADC L | 抵抗/負荷設計を追加、個別声ADC不要 |
| ADC電源ゲート/4ch入力切替 | Dカード用対策 | そのまま転記しない | 同一供給・STOP常時ADCを前提に必要性を再評価 |
| カード3.3V LDO | カード毎 | 小負荷カードはpin25補助電源で省略可 | Core/YMカードはローカルLDO、出力並列禁止 |
| PCM5102A/最終mute | ベース共通 | 維持 | アナログ音源もADC経由で同じ停止経路 |
| Si5351A/32pin connector | ベース共通 | 維持 | 外形/部品型番候補同じ、新用途5pin |
| I2C mux/自動ID EEPROM/絶縁 | 必須化しない | 追加しない | 手動profile、アドレス衝突は設定で解決 |
| 音源IC固有部品 | 音源毎 | 必要なものだけ維持 | 5V変換、PSG latch、PWM LPF、RF、R/C/DAC等 |

「音源側MCUもADCも無し」はnative I2C/SPI制御＋アナログ出力のICで成立する最小像。
AY/SN系のパラレルbusにはbridge/ラッチ、SN76477には制御DAC/スイッチ等が要る。
共通化のためだけの高機能MCU・汎用FPGAを再導入しない。

次の回路化ではADC入力2chのAC結合・バイアス・RC、補助LDOの100mA追加枠、5V総電流/熱、
STOP時ゲート初期値、clock/analog配線距離を確認する。Dの寸法や全品点数をEの確定値とはしない。
