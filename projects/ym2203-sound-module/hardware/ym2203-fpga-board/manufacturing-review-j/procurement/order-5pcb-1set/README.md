## Excelでの調整

新しいExcelはプロジェクトのGit管理外
`outputs/p2-review-j-order-5pcb-1set-20261118/p2-review-j-order-5pcb-1set.xlsx`。
以前のExcel、Gerber ZIP、検証記録は上書きしていない。

「購入リスト」E5=部品セット数1、F5=基板種類ごとの購入枚数5。
E列は今回必要数、F列は実装使用数、G列は販売単位、H列は手持ち、I列は注文あたり予備。
J列は購入単位数、K列は実装後残数。PCBのG列=5枚/ロット。
価格未確認60行にはPCB3行を含み、PCBのUSD見積は別表に示す。
この60行は60種類の入手不能品という意味ではない。

Gが空欄の行はJ/Kも空欄のままにする。見積で販売単位を確定してから入力する。
1セットから増やす場合は必要基板数も確認し、Kが負なら不足を解消する。
参照対応274件とそのタブの書式・内容は保持した。
数量・手持ち・包装切上げ・基板枚数を変更する再計算と、保存後のセル/表ヘッダーを検査した。
Excelデスクトップでの再計算は未確認。
