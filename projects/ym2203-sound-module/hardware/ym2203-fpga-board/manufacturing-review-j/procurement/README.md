秋月価格確認分の小計は**1セット6,290円、5セット22,430円**（ヘッダー予備40接点/注文込み）。
**30行分だけの小計**であり、MCU・IC単体・ソケット・基板代等の未見積や送料を含む総額ではない。
1セット/5セットの価格を線形に5倍しない。100本抵抗等の包装をまとめて使う計算。
初期の販売単位価格を使用し、数量割引は適用していない。
価格・在庫の出典は[supplier-observations.json](supplier-observations.json)と各行URL。
メーカー資料・販売ページの文章を転載せず、型番/包装数/価格などの確認事実を記録する。

## 端子と機構の数え方

- J02はbase64＋module64＝128個。MCUの四隅干渉を避ける独立端子。
- J03は**199接点**＝MCU128＋ベース外部18＋source SWD5＋シールドUNO/LCD40＋LCDモジュール8。
  PH-1x40SGを最低5本で切出し可能だが余裕は1接点。
  予備40接点/注文を入れ、初期発注は1セット6本、5セット26本。
- LCDハーネスは40ch中8chを使う。5セットなら40ch全てを使用する。
- FB3-10支柱11個＝音源4＋シールド3＋底脚4。積層7本には調整用ワッシャー/シムを追加。
  M3ネジ22本は上下固定を想定。LCDはM2支柱12mm×4とM2ネジ×8で別計上。
- 編集用S-42ノブ4個と外部音量のローレット軸用ノブは別。encoderは専用軸付き。

## ExcelとCSV

Excelはプロジェクトの`outputs/p2-review-j-fabrication-20261118/`に置く。
「購入リスト」のG列=販売数、H列=手持ち、I列=注文当たり予備を編集するとJ/K列の発注数を再計算する。
上部E5/F5のセット数は1/5を初期値とする。販売数が空欄の行は**発注数も空欄**のままにし、
未見積を「1個販売」と決め付けない。必要個数E/F列は見積依頼に使える。
1回の注文での手持ち控除・包装切上げを2ケースへそれぞれ適用する比較表であり、2回分の同時発注表ではない。

CSVはUTF-8。数式を持たない確認用スナップショットで、Excelの編集結果が自動でCSVへ戻るわけではない。
Excel計算器で手持ち/販売数/セット数と空欄/0を検査し、数式エラー0を確認した。
Excelデスクトップでの再計算は未確認。少数見積・メーカー図面照合・現物合わせを終えてから注文数を確定する。
全90行の一覧は[purchase-bom.csv](purchase-bom.csv)を参照。
