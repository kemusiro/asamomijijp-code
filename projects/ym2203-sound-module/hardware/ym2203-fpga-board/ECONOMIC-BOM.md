# Rev D案：Economic向け部品選定・候補BOM v0.1

2026-11-14。5枚、片面SMT、Pico 2とiCE40UP5K-SG48維持。Pico／YMソケットと、端子ピッチ2 mm以上で手実装しやすいリード付き部品を自前実装へ分けた。

**結論：選定した委託側29品種に、JLCPCBの「Economic and Standard」対応表示を確認できた。Economicを利用できる候補構成は組める。** ただし、在庫・余剰必要数・調達経路、全回路、片面配置、実注文画面での適合は未確認で、発注可否が確定したBOMではない。

正本は[economic-bom-plan.json](economic-bom-plan.json)。全品種は[候補一覧](ECONOMIC-BOM-TABLE.md)、[全体CSV](economic-candidate-bom.csv)、[委託SMT候補CSV](economic-smt-candidates.csv)、[自前実装候補CSV](owner-assembly-candidates.csv)に分けた。候補refは機能を表す識別名で、まだ回路図と照合した部品番号ではない。CPLは未作成。

端子ピッチは**隣接する電気端子の最小中心間隔**で判断する。パッケージ全長、列間隔、固定脚同士の間隔で細ピッチ信号端子を覆い隠さない。USB-Cは固定脚が大きくても信号端子が細かいため、コネクター全体を委託する。3225の4端子水晶も一方向の間隔が2 mm未満なので委託側に置く。

2端子SMDの本体寸法を「ピンピッチ」と同一視しない。抵抗と局所デカップリングは、実装費の追加フィーダー料がないBasicの0603（インチ、1608メートル）を選び、業者SMTへまとめる。端子ピッチ2 mm以上のリード付き部品を自前にする方針と、小型のBasic SMTを使う方針を両立させる。

自前対象の数値は既存Rev Cの図面／配置か、これから部品を選ぶための条件。すべてのメーカー図面を照合し終えた値ではない。ソケット・コンデンサ・精密抵抗など、まだ型番を決めていない自前部品をCSVでは空欄のまま残し、架空のメーカー型番を埋めない。

表の13品種・15配置に、Pico 2とYM2203Cを加えて主要IC／モジュールは**17配置**。初期の14〜15個という予算から増えた。3.3 VをPicoから供給できると仮定せず主基板用LDOを足し、電源監視も具体化した結果である。部品点数が減ると結論する段階ではない。

いずれもIC自体の直接実装。安価な互換名の別メーカー品や、SMTパッケージなのに「Wave Soldering」と分類された別商品を、同じ型番のつもりで置き換えない。JLCの商品名・Cコード・メーカー・パッケージ・Assembly Typeをセットで照合する。

### 電気条件からの選定理由

- データ用SN74LVC4245AはYM側5 V、FPGA側3.3 V。TTLの入力閾値、DIR/OE、無給電隔離を評価する。制御用8T245と同じものとして扱わない。
- 制御用SN74LVC8T245は3.3 V→5 Vの一方向で使う案。Rev Cの変換モジュールの同系統ICを直接実装する。AHCT541候補から、両電源・隔離条件を追いやすい候補へ具体化した。
- SN74LVC125Aは3.3 V給電で5 V入力を受ける4回路。SD/CLK/SHとIRQに使う候補。OEと電源OFF時の挙動は回路図で確認する。
- データ変換ICのOEを5 Vへプルアップする場合、FPGA端子へ5 Vを直結しない。Q_DATA_OEをMMBT3904で追加し、5 V側OEをコレクターで駆動する案をBOMへ含めた。制御バッファーのOEにもQ_CONTROL_OEを置き、既存のHOST_ARMで許可する案とした。信号極性・ベース抵抗・OFF時状態は回路レビュー対象で、GPIO追加や割当をしたものではない。
- アナログ合成の抵抗値・SSG負荷・無極性結合はRev Cを基準に維持する。DAC・アンプの変更でゲインを下げたり、SSGをデジタル合成へ変更したりしない。
- JLCのSi5351の説明には「8出力」という情報があるが、採用する10-MSOP品はメーカー資料に従い3出力として設計する。ライブラリの説明を回路仕様の正本にしない。

### 電源候補と残る条件

```text
外部5V → 5Vロードスイッチ → YM／アナログ5V
                         → TLV75533 → 3V3_RAW
                                       ├→ TLV75512 → FPGAコア1.2V
                                       ├→ 電源監視
                                       └→ IOロードスイッチ → FPGA IO／Si5351／DACの3.3V候補
Pico 2：従来のVSYS経路で給電。3V3出力と3V3_RAWを短絡しない。
```

コア成立後にIOを有効化する構成候補。TPS3808G01を2個使い、0.405 V基準のSENSEで5 Vとコアを監視する。5 V側100 kΩ／10 kΩなら公称閾値4.455 V。コア側187 kΩ／100 kΩなら公称1.16235 Vだが、**温度・公差・LDO下限・必要な停止時刻まで検証した値ではない**。CT、SENSEフィルター、PG合成、VCCPLLフィルター／給電は未確定。

Pico USBのみON、外部5 VのみON、3V3_RAWだけOFF、IOスイッチだけOFFの各状態で、無給電の監視出力を誤って「電源正常」と読まないこと、FPGA／Si5351等へGPIOやプルアップから逆給電しないことを確認する。これが済むまで起動回路の成立を宣言しない。

LDOの500 mA表示はそのまま使える消費電流の保証ではない。UP5Kの合成結果／Power Calculator、Si5351・DAC・バッファーの負荷、5 V→3.3 V／3.3 V→1.2 Vの発熱、基板銅箔と温度を計算する。出力CのDCバイアス後の容量がメーカー最小値を満たすことも必要。

## 3. 委託側の部品区分と費用の具体化

候補BOMの委託側は、**29品種：Extended 16、Basic 13**。同じMPNを使うロードスイッチ2個、監視2個、複数の抵抗・Cはそれぞれ1品種にまとめる。委託位置は110個／枚、5枚で550個という暫定数。数量を回路図から抽出したものではなく、電源端子、バイアス、信号終端等の設計予算である。

Extendedは上表の13品種＋USB-C＋水晶＋2.2 µF。100 nF、1 µF、10 µF、10 nF、MMBT3904、8種類の抵抗はBasic表示を確認した。部品区分は変わり得るため、アップロード時に再照合する。

[公開料金表](https://jlcpcb.com/help/article/pcb-assembly-price)と前回の料金スナップショットでは、Economicの段取り$8.18、ステンシル$1.53、Extended 1種$3.07なので、既知の分は次の計算になる。

```text
8.18 + 1.53 + 16 × 3.07 = 58.83 USD／注文
```

**この$58.83は製作総額ではない。** 生基板、全部品、実装点数、X線、端数・予備・最低数量、配送・税、書込み／動作検査、USB固定脚の追加作業やサービス固有費用を含めない。見積り前の現時点で、29品種の価格・在庫・部品ロス分を合わせた購入費は未確定。

自前のはんだ接合点は**137点／枚、5枚で685点**。Pico側オスヘッダーを未実装品から付ける場合はさらに5枚で200点。自前部品代・道具・消耗品・送料は必要で、委託BOMから外した部品代を総費用から消さない。

前回の「ソケットだけ自前」の総額は過去条件の比較資料として保持する。今回の部品数・自前範囲・電源回路は変わったため、その金額を新BOMの正式な価格へ読み替えない。

## 4. Economic利用可否の判定

| 確認項目 | 現在 |
| --- | --- |
| Pico 2とUP5K維持 | 候補BOMで確認 |
| 委託29品種のMPN・メーカー・Cコード | 選定、公開ライブラリの対応表示を確認 |
| Standard専用表示の選定品 | 今回の委託候補には含めていない |
| 自前の2 mm以上という条件 | 数値条件で分離。未選定部品の実寸照合は今後 |
| 片面SMT、4層、1.6 mm、緑、ENIG、120×100 mm | 注文画面でこの組合せが選べることは未確認 |
| 5枚分＋実装ロス・最低購入数 | 未確認。掲載在庫・価格の検索結果だけで充足を保証しない |
| パッケージ・MSL・リフロー | UP5KはMSL3。メーカー条件と業者工程の照合は未完了 |
| 機械配置・回路・CPL・ERC／DRC | 未実施 |
| 部品マッチング・正式見積り | 未実施 |

不足在庫は、同じCコードの補充、正規の調達方法、電気的に適合する別品を比較する。調達経路を変えてもEconomicを維持できるかは、その手段と注文画面で再確認する。単純に「在庫がなければ代行調達すればよい」とは扱わない。[BOM/CPLマッチング時の問題と対応](https://jlcpcb.com/help/article/common-bom-and-cpl-matching-issues-and-explanations)

## 5. 次に必要な設計資料

1. 自前部品のメーカー型番・図面、コア分圧と電源／消音の回路を確定する。
2. SG48の実端子、bank、固定SPI・クロック端子とPico信号をレビューする。承認済みRev CのGPIOを変更した実装ではない。
3. 実フットプリントで片面配置し、自前部品へこてを入れる空間、ソケットの挿抜、はんだ穴、取付穴を確保する。100／120 mmの従来の機能領域図へ全BOMが収まったとはまだ扱わない。
4. 回路図のrefから製造BOM／CPLを出し、今回の候補CSVと照合する。5枚の実装数と、購入数（実装ロス・最低数量を含む）を分ける。
5. Economicの部品照合・工程・価格を確認し、同じPico／FPGAを維持したStandard見積りも比較する。

今回の作業では、業者への照会・ファイル送付・部品取寄せ・購入・基板発注、GPIO割当やRTL／ファーム実装は行っていない。
