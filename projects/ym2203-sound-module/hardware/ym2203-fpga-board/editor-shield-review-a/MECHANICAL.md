# 操作面・機構・電源の条件

review Aは回路図と配置仕様。配線PCB/DRC/製造用データではない。

4つの手操作ノブとLCDの余裕を優先し、UNO標準外形より長い**76×96mm**を採る。
UNO座標で外形(-3,-3)..(73,93)、review I base上で(7,7)..(83,103)。
sourceはx90mmからなので7mmのXY間隔を維持する。シールド全体が従来の76×60予約域に収まるとの主張はしない。

| 部位 | UNO基準座標(mm) / 条件 |
| --- | --- |
| LCD包絡 | (-1,6)..(39,46)、40×40mmを仮予約。module本体・PH/cableを現物照合して取付穴確定 |
| encoder軸 | (52,16)、ノブ直径16mm以下 |
| NOTE / STOP中心 | (50,36) / (66,36)、6mm角ボタン |
| OP1..4中心 | (5,60),(17,60),(29,60),(41,60) |
| knob1..4軸 | (6,85),(25,85),(44,85),(63,85)、ノブ直径12mm以下 |
| base clock DIPアクセス窓候補 | (50,62)..(67,77)。指/細い工具で届くことを現物確認。窓の端とRV3/4の銅箔clearanceは配線時検証 |
| base ICSP keepout | (61,20)..(69,31)。裏面に部品・はんだ足を置かない。ICSPを嵌合接続しない |
| 支持候補 | UNO(66.04,17.78)/(66.04,45.72)/(13.97,50.80)。base H9/H10/H12へ一致 |
| H11 | ヘッダーに近いので従来どおりねじを使わない |

32接点のUNO雄headerを**シールド裏面**へ実装。pin番号は常に上面視の既存接点表と照合する。
対向面間下限10.5mm、baseのこの領域の背高部品5mm以下、shield裏面突出3mm以下なら余裕2.5mmという条件付きモデル。
雌の8.51mm＋雄樹脂2.54mmの公称11.05mmを候補とするが、採用headerの現物挿入で確認する。
無理に先に決めたスペーサーへ締め込まない。socket筒やheader pinを切り詰めて高さを合わせない。

裏面は低いFRAM/0805のみを想定。操作子は表、THT leadは裏3mm以下。
LCDは別モジュールを上面の絶縁支持へ載せ、裏の金属やコネクタがshield銅箔に接触しない構造にする。
connector J5はmodule用ハーネス接続口で、LCD footprint/取付穴を検証した意味ではない。
encoder/ノブ/スイッチの高さを揃える前面パネルは任意。操作荷重をUNO pinだけで支えず3支持を使う。

長いshieldはbaseのSTOPを覆う。そのためshieldのD0 STOPを同じglobal STOPへ接続するfirmwareが必須。
base TEST(7,108)は外形下側に残るが、押下空間を含む確認は未実施。RUN/BOOTは右外側に残る。
clock DIPの窓、USB cableの手元、panel/支持/ノブの相互干渉を実物で確認してからPCB外形を確定する。
これらはreview Iの実物嵌合試験を置き換えない。

## 電源と製作前確認

LCDの80mAは採用上限でありデータシート保証値ではない。最大輝度・全白で電流と温度を測る。
baseのUNO3V3上限100mA、AUX設計500mA以内を維持し、LCDだけで上限を超える個体なら無条件で実装しない。
IOREF追加8mA予算は4potの最小抵抗8kΩ、encoder2.7k pullと他pull、FRAMを含む。
ENC A/Bの接点電流は約1.2mA、押込みは4.7kで約0.7mAとする。
AUX/IOREFは別railであり、両3.3Vを導線で結ばない。
全体はbase外部5Vから同時給電し、無通電でshield交換する。別USB電源やLCDだけの外部電源は付けない。
GPIOはrail安定までHi-Z、LCD reset/CSを適切に設定して初期化。AUX/LCD立上り前のpush-pull出力を避ける。

次工程で全32padの嵌合、ポット/encoderの実footprint、ICSP裏面keepout、窓と取付穴、電源/音声とLCDのノイズ、
LCD/FRAM中のSTOP応答を検査する。現段階でGerber発注・実機合格とは扱わない。
