# P2層構成の検討A：主案4/2、比較案2/2

2026-11-18。ユーザー方針により、**ベース4層・音源2層を主案**、
**ベース2層・音源2層を比較案**とする。開口なし編集シールドは両案とも現行2層。
今回の工程は構成・再配線方針の検討であり、既存CADを変更せず、2層PCBもまだ作成しない。
正本は[plan.json](plan.json)、読取監査は[native-audit.json](native-audit.json)。

## 方針と検証段階

| 項目 | 現行4/4（比較基準） | 主案4/2 | 比較案2/2 |
| --- | --- | --- | --- |
| ベース | review J、4層 | 現行Jを維持 | 表裏2層へ再配置・再配線 |
| 音源 | review I、4層 | 表裏2層へ再配置・再配線 | 主案と同じ2層音源を共用 |
| シールド | 開口なしB、2層 | 維持 | 維持 |
| 基板外形 | 220×142 / 100×100 / 76×100mm | 同じ外形で検討 | 同じ外形で検討 |
| 新しい配線済みCAD | 現行のみ存在 | 未作成 | 未作成 |
| 新しいERC/DRC・機械検査 | 現行記録あり | 未実施 | 未実施 |
| 新しい製造費・送料見積 | 4/4の記録あり | 未取得 | 未取得 |
| P2実機受入 | 未実施 | 未実施 | 未実施 |

主案の音源2層を先に成立させ、比較案でも同一カードを使う。
ベース2層の難度が高くても主案を止めず、比較結果だけで現行Jの配線や製造データを上書きしない。
`active-plan.json`等の既存CAD参照は、最新の検証済み候補である4/4のJ/Iを指したままにする。
新しい目標層数は別の`layer_study`参照で区別する。

## 現行native PCBから確認した配線負荷

KiCad10.0.5のpcbnewでJ/Iを読み取った。保存・層変更・zone再充填は行っていない。
長さは分岐を含むtrackの総和で、端点間距離・遅延・ノイズ量ではない。

| 項目 | ベースJ | 音源I |
| --- | ---: | ---: |
| track segment総数 | 2,055 | 1,160 |
| 表面 / 裏面 / In2 segment数 | 1,100 / 273 / 682 | 731 / 191 / 238 |
| In2上のtrack総延長 | 約3,767mm | 約1,076mm |
| 全track長に対するIn2比率 | 約44% | 約30% |
| In2を使うnet数（電源を含む） | 67 | 32 |
| via穴0.20 / 0.30mmの個数 | 56 / 173 | 85 / 65 |

In1は両基板ともGND zoneで、trackは0本。In2には5V zoneに加えて上表の配線がある。
ベースはEXT_D2/D8/D9/D10/D12/D13とSWDIO/SWCLKが現在In2だけに配線されている。
音源も内層の配線量は少なくなく、層削除・自動層置換だけで2層にできる状態ではない。
これらの比率やnet数から、2層で配線可能かを算術的に判定することはできない。
GND zoneの存在・面積だけでも、信号の戻り道の連続性は証明できない。

## 共通して維持する条件

- PGA2350、Core2350B0、実YM2203C、Si5351A、ベースのPCM1863/PCM5102Aを維持。
- H/GのGPIO・回路net・40接点KEY6・UNO R3の信号配置を変更しない。
- 第一候補では外形1.6mm厚、コネクタ・ソケット・取付穴と右側DIP/STOP/TESTの位置を固定。
  2層での配線成立が難しい場合は、無断で基板拡大やGPIO変更をせず、制約として報告する。
- SMT部品の再配置は将来の候補で許容する。必要なら0Ω抵抗による交差も検討するが、
  今回は部品追加・BOM変更をしない。追加時は数量、実装順、面間干渉を明示する。
- HOSTのopn1/4MHz、0x42/100kHz、YM22S002、64byte STATUS、PUSH32、FIFO1024、
  1000ms lease、USB CDC/MIDI、所有権切替、停止・再接続時の無再演奏を維持する要件。
  配線検討はP2用firmwareの実装やRev Cでの合格結果の転記を意味しない。

## 主案：ベース4層・音源2層

ベースのUSB・ADC/DAC・電源/GNDと、右側操作入力の配線を現行Jのまま保持できる。
音源のみを再配線するため、両方2層より変更範囲を限定できる、という設計上の判断。
2層音源の配線成立や音質はまだ保証しない。

音源では、YMのFM受信Y_SD/Y_SHをCore側受信回路の近くで表面にまとめる。
現行の総配線長は約16.17/17.92mmで、両方とも表面のみ。
この短い受信経路を優先し、外部バスや低速制御を周辺へ回す。
Y_CLK（約59.90mm）とY_PHI_M（約28.85mm）、I2Sクロック/dataは、
連続するGNDの上を通すことと、SSGのanalog Lへの近接・並走を避けることを優先する。
analog Lは現行約71.31mmでIn2を含むため、2層化時に経路を組み直す。

表面を主な配線面、裏面を可能な限り連続したGND面とする。
ただし裏面JMODや多数のPTHソケットがあるため、全面を理想的な無欠損GNDにできるとは仮定しない。
裏面の横断配線を必要最小限にし、GNDの狭窄・孤立島・長い迂回を確認する。
内層5V補助面の代わりに太い給電経路を設け、CoreとYMへの分岐・デカップリングを確認する。
ADC・最終DACは元からベースにあり、音源へのADC/DAC追加は不要。

## 比較案：ベース2層・音源2層

共通の2層音源に加え、ベースも再配置・再配線する。
USB、ADC入力/VREF、DAC/電源・クロック周辺を先に配置し、裏面のGND経路を予約する。
UNO、LED、DIP、ボタンなどの低速配線は周辺の回廊へ回す。
PGA/UNO/G40の固定端子へ多数の信号が集まるため、広い基板面積だけで配線余裕があると判断しない。

現行USB D+は表面とIn2を使う約32.76mm、D−は表面のみ約30.53mm。
2層案では単純な層移動ではなく、D+/D−を一組として引き直し、直下のGNDを横断配線で切らない。
RP2350公式ガイドのUSB例は1mm板で、1.6mmの2層板へ同じ線幅/間隔をコピーしない。
PGAモジュール内とソケットを含む全経路、USB-C周辺の分岐も評価対象とする。
既存4層Jも90Ω保証・eye測定済みではないので、現行をUSB規格合格の基準品とは扱わない。

ADC_L/Rも現行約21.28/29.92mmでIn2を使う。
PCM1863の入力・基準電圧・デカップリングを小さな範囲へまとめ、クロックや操作配線の戻り電流が
その範囲を横切らないように配置する。AGND/DGNDの分断スリットは基本にしない。
PCM1863データシート§12.1には2層PCB実装が明記されており、ADC自体が4層必須という制約はない。

5V/3.3Vは電源面の除去を補う配線幅・面積を確認し、
TLV1117LV33の放熱TABと周囲の銅箔を維持する。前回の電流/熱予算だけで2層版の温度を合格としない。
最終muteゲート、pull-down、STOP/TEST配線も省略しない。

## 費用比較で揃える条件

第一比較は基板各5枚、部品1セット、FR-4、1.6mm、緑/白、ENIG1µinch、外層1oz。
4層ベースの内層は現行1ozを維持。2層化だけを理由にHASLや板厚変更を混ぜない。
シールドは同じ2層データなので、その費用差は発生しない前提。

音源は現行0.2mm viaが85個ある。2層で0.3mm viaを優先できるかも検討するが、
ソケット/IC周辺で必要な穴まで無理に拡大しない。0.2mmを残す案と0.3mm化できた案を区別する。
層数と小径穴の追加料金は別の要因であり、過去の4/4見積を比例計算して節約額にしない。
ジャンパー追加があれば部品費・手実装工数も加える。
**4/2・2/2の製造費・送料は未見積**。最終via規則と配線済みGerberが決まってから再比較する。
過去の[4/4・各5枚見積](../manufacturing-review-j/procurement/order-5pcb-1set/PCB-QUOTES.md)と購入表は保持する。

## 次の設計工程と判定

1. 別のCAD候補として音源2層を作り、既存pin/net・固定座標を照合する。
2. 未配線0、ERC/DRC/回路図差分0と、GND/clock/SSG・電源経路を確認する。
3. 同じ音源を使ってベース2層候補を作り、USB・ADC/DAC優先で成立性とジャンパー必要数を比較する。
4. 両案のソケット・裏面リード・開口なしシールドとの積層を再検査する。
5. 配線済みデータの製造見積と、必要なP2実機回帰項目を提示する。

2層化の評価では自動配線の完了率やDRC0だけを合格条件にしない。
GNDの戻り道、USB配線形状、電源/熱、clock/音声干渉は別途レビューし、
音質・USB通信・STOP/leaseの動作は最終的にP2実機で確認する。
現在はこのリストの前段階にあり、新しい2層版の成立・製造可能・実機合格を宣言しない。
