# Rev D案：5枚・片面SMTとソケット自前実装の費用比較

2026-11-14。Pico 2とiCE40UP5K-SG48を維持する。前回の[全委託U案](UPPER-COST-ESTIMATE.md)に対し、片面SMTとし、Pico 2用ピンソケット・YM2203C用ICソケットだけを自前実装するS案を比較した。**公開実装料金＋仮予算の比較で、正式見積りではない。**

現在の部品選定は[2 mm以上の自前実装を含むEconomic候補BOM](ECONOMIC-BOM.md)を参照。この文書のSはソケットだけ自前という以前の比較条件で、金額を新BOMへ転用しない。

## 1. 比較条件

| 項目 | 前回U | 今回S |
| --- | --- | --- |
| 実装枚数 | 5枚 | 5枚 |
| 制御／FPGA | Pico 2／iCE40UP5K-SG48 | 同じ |
| 基板の費用仮定 | 4層・120×100 mm・ENIG、5枚 | 同じ。2層化や面積縮小の節約を混ぜない |
| SMT | 両面を予算化 | 片面へまとめて委託 |
| Pico用ピンソケット | 業者実装 | 2列20ピン、合計40接合点を自前実装 |
| YM2203C用ICソケット | 業者実装 | DIP40、40接合点を自前実装 |
| 音量器、ジャック、HOST端子など | 業者実装 | 引き続き業者実装。THT全体を自前に移す意味ではない |
| Pico 2とソケットの部品代 | 総部品予算に含む | 自前購入分に振り替え、総部品予算からは引かない |
| SMT接合点／X線 | 500点／UP5K 1個を仮定 | 同じ。検査削減による節約を計上しない |
| 業者のTHT接合点 | 140点／枚という従来の仮定 | ソケット80点を引いた60点／枚という仮定 |
| 書込み・基本検査予算 | 注文当たり$50〜150という仮定 | 比較用に同額の予算枠を残す。ただし検査対象・受託方法は変更が必要 |

片面とはSMTの実装面であり、銅箔の層数ではない。FPGAのQFN、クロックのMSOP、DACのTSSOPは委託へ残す。PicoやFPGAを別製品へ変更して安くする案は含めない。

自前実装は基板1枚当たり80点、5枚で400点。Picoがヘッダー未実装品なら、Pico本体側のオスヘッダー40点／個も別に必要となる。今回はこの追加40点の委託費削減を計上しない。ヘッダー付きPico 2を購入する場合を含め、残るTHT予算60点や部品代は、全BOMと作業範囲を確定して再計算する。

## 2. 総費用の比較

前回と同じ160円/USD、税等の予算余裕10%、予備費20%を適用。金額は1,000円単位で切り上げた計算値で、実際の価格がその精度で分かっている意味ではない。

| ケース | 5枚合計の仮予算 | 1枚当たりの仮予算 | 同条件でのUからの削減額 |
| --- | ---: | ---: | ---: |
| 前回U：両面SMT・全委託 | 115,000〜204,000円 | 23,000〜41,000円 | 基準 |
| S：片面Standard・ソケット自前、共通物流 | 106,000〜196,000円 | 22,000〜40,000円 | 約8,500円／注文 |
| S：自前購入の追加送料も計上 | **106,000〜198,000円** | **22,000〜40,000円** | **約6,400〜8,500円／注文** |

自前購入の追加送料は$0〜10という仮予算。すでに予定する購入へ同梱できれば0、別発送が必要なら増える。道具・消耗品の新規購入と、自分の作業時間に対する金額は含めていない。

同じ条件に対応する低側・高側を引いた比較であり、独立した見積り幅の最小と最大を組み合わせた差ではない。丸める前の差額と各費目は[検査JSON](verification/socket-cost-check.json)へ保存した。

### 削減の内訳

[公開料金表](https://jlcpcb.com/help/article/pcb-assembly-price)（表示更新日2026-10-22、2026-11-14確認）のStandard欄を用いる。

| 変わる項目 | 計算 | 予算換算後の削減 |
| --- | --- | ---: |
| 段取り＋ステンシルを両面→片面 | ($51.12＋$16.42)−($25.56＋$8.21)＝$33.77 | 約7,132円／注文 |
| ソケットの委託実装を省く | 80点×5枚×$0.0164＝$6.56 | 約1,385円／注文 |
| 合計 | $40.33×160×1.10×1.20 | 約8,518円／注文 |
| 自前購入の追加送料 | $0〜10×160×1.10×1.20 | 上の節約から0〜約2,112円を差し引く |

残りのTHTを業者へ頼むため、注文単位の手はんだ工程費$3.58は残す。ソケット2種を外すだけで全フィーダー・治具・検査費が消えるとも扱わない。両面で重複したフィーダー投入が減る可能性はあるが、元の35〜55投入自体が仮定なので、基本比較では同じ数を保持した。

**部品代、基板代、調達、検査、配送、その他の仮予算が残るため、この変更だけで総額が半減する計算にはならない。** 一方、現在の総額は上振れ用の仮予算を多く含み、正式見積りがこの額より安くならないという意味でもない。

## 3. 手元へ移る部品代

見積り上の総部品予算は、引き続き$45〜70／枚、5枚で$225〜350。

| 購入区分 | 5枚分の仮配分 |
| --- | ---: |
| 自前：Pico 2、ソケット、Pico用ヘッダー | $35〜50 |
| 委託先：FPGA、その他IC、R/C、残りの端子等 | $190〜300 |
| 合計 | $225〜350 |

配分はPicoの従来予算$5／枚＋ソケット等$2〜5／枚という**仮置き**。確認済みの商品単価ではない。自前分を委託先への支払額から外しても、自分の購入費として戻すため、総費用では同額を維持する。手持ちPicoを流用する場合の追加購入不要分は、U/S両方へ同条件で適用して別に比較する。

## 4. Economicが使える場合の追加比較

[業者の実装能力](https://jlcpcb.com/capabilities/pcb-assembly-capabilities)には片面SMTとTHTの混載が掲載されているが、このBOMでEconomicを利用できるかは未確認。QFN実装そのものが可能なことと、選定した各型番・リフロー条件・調達経路がサービスに適合することは別に確認する。

EconomicではBasic／Preferred Extendedのフィーダー投入料が免除される一方、課金対象Extendedは1種$3.07。StandardはBasicを含め1投入$1.53となる。[料金表](https://jlcpcb.com/help/article/pcb-assembly-price)、[部品区分の説明](https://jlcpcb.com/help/article/pcb-assembly-faqs)

| 条件付き試算 | 5枚合計の仮予算 | 意味 |
| --- | ---: | --- |
| E：課金対象Extendedが15〜25種 | 96,000〜188,000円 | 35〜55種中、残りを免除対象にできるという未確認の仮定。Uより約1.7〜1.9万円安い |
| E感度分析：35〜55種すべて課金対象 | 109,000〜207,000円 | 料金プランの名前だけでは安くならない。高側ではUより高くなる |

どちらもSと同様、自前購入の追加送料$0〜10を含める。経済的なプランに適合する品種へ置き換える場合も、Pico 2とUP5K-SG48は維持し、電源順序・入力閾値・独立許可を満たすことが条件。型番照合前にEの安い方を採用価格としない。

## 5. 実装と検査の依頼条件

- 製造BOMは全必要部品を持ち、業者実装リストからPico用ピンソケット・YM用ICソケットと自前のPico本体を外す。回路上不要なDNPではなく、納品時未実装として指定する。
- その他のSMTとTHTは委託へ残す。Pico／YMの未実装穴が後から使える状態であることも組立図へ明記する。
- PicoもYMも装着されていない基板では、そのまま通常の演奏試験をできない。業者へ頼む電源・短絡・部品・はんだ検査、必要ならテストポイント経由の確認と、装着後の最終動作試験を分ける。
- 計算では書込み／基本検査の$50〜150予算枠を維持したが、同じ検査を同じ価格で受託できるとは確認していない。書込み・最終音出しは自前ソケット実装とPico／YM装着後に行う。業者側の検査費が変われば予算枠を置き換える。
- Picoやソケットを自前実装して完成するまで通電しない。製造後の検査で必要な通電は業者の検査手順・電源条件による。ソケットを省くことを理由に安全回路を省略しない。

片面に収まる全フットプリントと配線は未確認。まず120×100 mmの同じ外形で比較し、片面化に追加面積・取付穴の変更が必要なら、生基板代と配送重量も再見積りする。

## 6. 再計算

入力は[socket-cost-inputs.json](socket-cost-inputs.json)。前回のUの入力・計算結果を改変せず参照し、共通費目を引き継いで差分を求める。

```sh
python3 hardware/ym2203-fpga-board/tools/compare_socket_cost.py --write
python3 hardware/ym2203-fpga-board/tools/compare_socket_cost.py
```

[比較CSV](socket-cost-summary.csv)と[検査JSON](verification/socket-cost-check.json)を生成する。部品代の自前／委託先配分が総額に一致することと、差額が段取り変更＋80ピン×5枚の差に一致することを照合する。見積り依頼・部品購入・発注は行っていない。
