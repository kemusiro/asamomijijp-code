# Rev D案：全実装委託の一次予算シナリオ U

2026-11-14。Pico 2を維持し、ほかのICを直接実装する構成について、**手実装の制約を外した、費用が上振れする比較ケース**を作る。正式な業者見積りではなく、公開料金と仮定を分けた予算モデルである。

一次見積りの検討順はU（全委託）→A（片面SMT委託）→B（部分SMT委託）とする。今回のUを正式なPCB構成として採用した意味ではなく、従来の[手実装も考慮した案](ASSEMBLY-AND-SIZE.md)を費用削減時の比較対象として残す。

今回の追加比較は[5枚・片面SMT＋ソケット自前実装](FIVE-BOARD-COST-COMPARISON.md)を参照。以下のUの条件・金額は比較基準として保持する。

## 1. 見積り対象の構成

| 項目 | U案で費用に見込む条件 |
| --- | --- |
| 制御・音源 | Pico 2モジュール維持、実YM2203CはDIP40ソケット。その他は単体ICを直接実装 |
| 基板 | FR-4、4層、120×100 mm、ENIG。実フットプリントや配線が成立した外形ではない |
| SMT | 両面実装を許容したStandard相当のサービス。実配置で片面に収まれば減額比較 |
| FPGA | iCE40UP5K-SG48、QFN-48、底面パッド。ピン数不足になる別パッケージへ小型化しない |
| クロック／DAC | Si5351A-BのMSOP-10、PCM5102AのTSSOP-20 |
| その他のIC／受動部品 | 小型TSSOP等を許容。0603（インチ）＝1608（メートル）も使用可。部品の電気条件が優先 |
| THT | ソケット、音量器、ジャック、HOST端子、Pico用ヘッダー等も業者実装。利用者によるはんだ付けを不要にする見積り条件 |
| 検査 | 外観・AOI、QFNのX線、通電・基本動作、Pico書込みを条件として提示。受託範囲は別途照会 |
| YM本体 | 手持ち品を実装済みソケットへ挿す。YMの新規購入・真贋検査は費用に含めない |
| ロット | 実装2／5／10枚を比較。2枚実装でも生基板5枚分を予算化 |

手実装の難しさを理由にSOIC／0805へ限定しない。小型品が大型品より高いとは限らないため、難しいパッケージを使うだけで費用を水増ししない。両面SMTも必須仕様にせず、費用側の余裕を見込む条件とする。小型品を使うことから100×100 mm以下へ縮小できるとはまだ結論しない。

従来の仮配置図は**片面機能領域の検討図**であり、U案の両面配置図ではない。Picoソケット直下の干渉、下面SWD、取付穴、コネクター・つまみの外部空間、アナログ帰路を含めた再配置が必要。

## 4. 一次計算結果

上記の条件を低側／高側でそろえて足した結果。確率的な価格範囲や保証された上限ではない。為替仮定・税等余裕・予備費まで含め、1,000円単位で切り上げた。

| 実装枚数 | 生基板枚数の仮定 | 仮予算合計 | 1枚当たりの仮予算 |
| --- | ---: | ---: | ---: |
| 2枚 | 5枚 | 83,000〜157,000円 | 42,000〜79,000円 |
| 5枚 | 5枚 | 115,000〜204,000円 | 23,000〜41,000円 |
| 10枚 | 10枚 | 173,000〜296,000円 | 18,000〜30,000円 |

一次判断には、**5枚なら約12万〜21万円の予算シナリオ**として見る。2枚は注文総額が低い一方、固定費を少数で割るため1枚単価が高い。10枚はこの比較で注文総額が最も大きい。完成歩留まりを実測した値ではなく、1枚単価は完成予定枚数で割った計算である。

例として5枚の場合、部品$225〜350、生基板$50〜100、注文単位の公開料金モデル$87.99、フィーダーモデル$53.55〜84.15、SMT／THT／X線モデル合計$23.68、書込み等$50〜150、調達予備$10〜50、その他$0〜30、物流$40〜90で、小計$540.22〜965.82。ここに換算・税等の余裕・20%予備費を適用する。

```text
仮予算円 = USD小計 × 160 × 1.10 × 1.20
```

対象は海外PCBAを参考にした製造・実装の仮予算。設計・RTL／ファーム開発の工数、国内業者へ一括委託する費用、YM2203C購入、ケース・電源アダプター・HOST側Pico、検査治具の新規開発、設計修正後の基板一式再発注は含めない。供給不足による無制限な上乗せや再製作まで含む絶対上限ではない。

## 5. この額から絞る順序

1. 全BOM、実装面、Gerber／CPLを作成し、推定の接合点・フィーダー投入数・調達価格を実数へ置き換える。
2. 同じU案で2／5／10枚の正式見積りを比較し、基板枚数と実装枚数、余剰部品を分ける。
3. 両面を片面へまとめたA案を比較する。4層のまま片面SMTにできるなら、その差額を先に確認する。
4. THTだけ手実装、次にSOIC・0805を増やしたB案と比較する。小型パッケージを大型品へ変える場合は別PCBの配置・配線を確認する。
5. 独立許可、電源順序、入力閾値、デカップリングは維持したまま、部品調達と実装範囲で費用を下げる。

一次予算は実装難度を優先条件にしないため、手実装しやすいパッケージへの限定を外す。一方、SOIC品が安価・調達容易なら使えるので、無理にQFNへ置換しない。現状のFPGAをWLCSPへ変更したり、手持ちYMを異なる音源ICへ変更したりしない。

## 6. 再計算と確認状態

入力は[upper-cost-inputs.json](upper-cost-inputs.json)。公開料金、価格参照、仮定、対象外を分離した。[upper-cost-summary.csv](upper-cost-summary.csv)と[検査JSON](verification/upper-cost-check.json)を次で再生成できる。

```sh
python3 hardware/ym2203-fpga-board/tools/analyze_cost.py --write

```

Python標準ライブラリのDecimalで計算し、保存内容との一致を検査する。実装業者への問合せ、見積り依頼、データ送付、部品購入、発注は行っていない。
