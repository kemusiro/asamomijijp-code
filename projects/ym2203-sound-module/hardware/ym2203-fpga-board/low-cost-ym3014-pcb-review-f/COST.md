# 各5枚・部品1セットの費用

[review Eの購入表](../low-cost-ym3014-schematic-review-e/purchase-plan.csv)の277実装参照・81購入行を維持する。新しい基板外形は予定枠内のbase100×100mm4L、source100×80mm2L、panel100×76mm2L。標準ビアと鉛フリーHASLを前提とし、ビア穴埋め加工・PCBAを追加しない。

| --- | ---: |
| 部品（販売単位・余り・機構部品枠を含む） | 19,562円 |
| 部品送料 | 550円 |
| 裸PCB3種類×各5枚の商品枠 | 3,824円 |

| 為替・未確定支持材・決済などの予備枠 | 2,500円 |
| 合計 | **29,936円** |

約30,000円を目指す計画として寸法を維持した。新しいGerberをカートに投入した送料込み確定見積ではない。商品/送料はEで区別したメーカー観測と過去同寸法PCB枠を引き継ぎ、税・為替・配送・在庫で変わる。20mmパネル脚、12mm基板間支柱とLCD支柱、ねじ/ナットは既存の機構部品1,000円枠を購入時に具体化し、差額は予備枠で扱う。特殊な高さ調整ソケットを必須にしない。

YM2203C流用、YM3014B-F支給は0円。MCU3枚、ADC、I2S、出力DAC、LCD/保存機能を削除して価格を下げたものではない。基板15枚を買っても実装は1セットだけ。工具・ケース・PCBA・工賃・将来の別音源基板は含めない。予備枠2,500円を確定部品代と二重計上しない。
