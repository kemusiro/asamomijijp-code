# 互換性と未実装範囲

review Eから全277部品の値・端子番号・端子名・電気属性・ネット、承認済みGPIOを維持する。変更は部品配置と物理ランド、取付穴、銅箔配線、表示だけ。Rev CのHOSTライブラリ、USB-MIDIコード、ファームウェア受入ログは変更しない。

| 境界 | 維持する契約 |
| --- | --- |
| 操作側PicoのHOST | I2C 0x42 / 100kHz、既存v2 BEGIN/APPEND/PLAY/KEEP/STOPとWYM1順序・CRC・完了の意味 |
| USB-MIDI / CDC | MIDI Note On/Off/Panic、CDC操作、I2Cとの排他的所有権、旧ノートを自動再生しない復帰 |
| 停止 | STOP/リース/USB切断時の所有者別停止、最終DAC XSMTゲート、音源ENABLE/RUN、キュー破棄と明示再開 |
| アナログ | 37=FM、39=SSGをPCM1863で取り込み、ベースで合成してPCM5102Aへ出力 |
| I2S | 31/33/34の入力経路とRX制御を保存。通常YM3014プロファイルでは同じFMを二重加算しない |
| パネル | 3.3V I2C別ポート、音色編集・保存・外部取出しの契約を維持 |

これは端子と設計契約の保存。新しいベースRP2350A・音源RP2350の分担、PCM1863、YM3014B-F、クロック設定、ミックス、パネル制御に合わせるP2ファームウェア移植は未実装であり、Rev C用UF2のバイナリ互換を保証しない。配線/DRCの合格を既存HOST・MIDIによる実機合格へ読み替えない。
