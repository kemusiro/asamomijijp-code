## 再生成

`baseline-plan.json`はGの保存スナップショット。価格観測を反映し、XLSXはGの元ファイルを読み込んで必要なセルだけ変更する。

```sh
python3 tools/update_plan.py
node tools/build_purchase.mjs
python3 tools/verify_purchase.py .
```

XLSX生成には`@oai/artifact-tool`のbundled runtimeを使用する。別の場所で実行する場合は`--source-workbook <GのXLSX>`を指定する。CSV/XLSX出力は同じデータから検証する。XLSXはGit管理外の`local-output/`へ生成し、テキストのCSV/JSON/ツールを管理する。
