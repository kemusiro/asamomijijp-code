# レビューD：電源・音声配線の確認範囲

## 容量と銅箔

電源割当はレビューCを維持する。PGA3V3は275/300mA、ベースAUXは150/500mA、
Core MCU3V3は205/800mA、ADC3V3は60/500mA。CoreのLDO800mAはIC定格で、モジュール上の連続供給の熱保証ではない。
音源5Vは415mAの割当、受入上限500mA。全体は955mA、音源500mA枠で1.040A。
5.1Vクラス2Aを候補とする。MCU180mA等は設計上の割当であり、最大実測電流ではない。

PTCはMF-MSMF150/16X-2、hold1.5A@23°C／1.25A@40°C、R1max0.12Ω。
主5V配線は0.50mm以上、In2.Cuの5V面で補助する。GND面はIn1.Cuで、そこへ信号配線を置かない。
MCU3V3にはB.Cuの補助面。ADC3V3は別レールの局所面と配線。AUXの局所接続は0.18mmを含むが、
150mA枠の分岐であり、1.040A入力幹線へ0.18mmを使うものではない。
ADC・DACの100nFは各IC近傍、YM VDDのC19/C20、両LDOの入出力コンデンサも局所に配置した。

35µm銅、抵抗率0.0175Ω·mm²/m×温度係数1.2、幅0.50mmの感度計算では、
仮のベース160mm区間が0.192Ω、仮の音源80mm区間が0.096Ωとなる。
1.040Aで0.200V＋PTC0.125V、音源415mA区間で0.040Vという厳しめの値になる。
これは枝を含む実配線総長から導いた最大経路ではなく、**電圧降下の感度条件**。
補助面・実負荷の分流・接点抵抗・ケーブル抵抗を含む電源網解析でもない。
5.1Vという表示だけでYMの最低電圧を保証せず、通電時に21番端子を測定する。
無負荷YM端子で5.25Vを超えるような調整をしない。

部品温度、レギュレーター放熱、PTCと接点の電圧降下は未実測。初回は周囲40°C以下、シールド負荷なしで確認する。
UNOの3V3・任意5Vは各100mAまで。5VはJP5Vを閉じた場合のみ、IOREFは3.3Vを維持する。
USB VBUSは検出のみ。3V3レギュレーター出力の並列接続、ベース／音源の電源絶縁は行わない。

## 音声・クロック

全長はネイティブの分岐を含むセグメント合計であり、ポイント間最短経路や位相差の証明ではない。
`routing-review.json`へ全ネットを出力する。

PCM1863の入力整形は分圧→TMUX→AC結合→4.7kΩ→ADC＋BAT54Sクランプ。
FM生入力とADC前段は基板内で完結し、基板間には完成I2Sだけを返す。
デジタル合成、SRC、AGC無効、SSG音量校正はP2用ファームウェアの次工程。
元の負荷・保護定数を、配線を短くするために変更していない。

Si5351A水晶はIC近傍で配線し、クロックとFM入力にはGND面の戻りを確保する。
48kHz/BCK3.072MHzの共有クロックと、可変YMクロックは別系統。
4MHz以外はクロック設定・SRC・楽曲メタデータの実装と実測を伴う。既存WYM1/HOSTへ新形式を混ぜない。

製造業者の積層・誘電率・銅厚は未確定。USBはFull Speed用の試作経路であり、
90Ω検証・ESD／EMC適合・I2Sタイミング・FM受信安定性・音質をDRC合格から推定しない。
