# PCBレビューD：ソケット・積層・手実装

この資料は未製作の候補に対する組立条件。最初にソケットとコネクタ各1組で高さと嵌合を確認する。

## MCUソケット

ベースのPGA2350、音源のCore2350B0は25.4mm角だがピン互換ではない。
Coreは公式寸法図のラベル付き上面図と公式回路図から64接点を転記した。
`core-pad-coordinates.json`と四つの`P2D:Core2350B0_P*_IndividualSockets`が物理位置の正本。
FPCが上面右上に来る向きで配置する。GND、VBUS、3V3、RUNの位置を通電前に実物と照合する。

個別ソケット候補はMill-Max0300-2-15-15-47-27-10-0。0.64mm角ピン対応に限定する。
数量はベース64＋音源64＝128。回路BOMのMPGA／JCOREは接点群を表すため、通常の2×8ソケットを代わりに購入しない。
丸ピン用ICソケットへ角ピンを押し込まない。

パッド径1.90mm、仕上り穴1.20mm。公称環状幅0.35mm。
ソケット最大フランジ2.032mmはパッドよりわずかに広いため、**裏面からはんだ付け**する。
穴径公差・端子径・はんだ濡れを実物1本で確認する。パッド径を旧版の2.05mmへ戻す場合はDRCと接地面を再検査する。
1.90mmにより2.54mmピッチ、面クリアランス0.20mmで、GND面の通り道が公称0.24mm残る。
ソケット実体はそのままで、フランジ間の保守的余裕は0.408mm。

ソケット上面高さ約5.33mm、MCU基板下面をキャリアから9.5mmに揃える治具を前提にする。
0.64mm雄ピン＋2.54mm樹脂＋約6mm自由長の候補で、実挿入3.5..4.5mm程度、底付きなしを確認する。
下面部品3.6mmを想定してキャリアとの隙間5.9mm、上面高さは13.1mmの予約枠とする。
MCU下面に別の部品を追加しない。CoreのFPCは上面右上から横へ引き出せることを実物で確認する。

## 基板間とUNO

JMOD：ベース表面SSW-116-02-G-D、音源裏面TSW-116-07-G-Dを候補にする。
雌の高さ8.51mm＋雄の樹脂2.54mm＝基板対向面間11.05mmを公称モデルにする。
雄の嵌合ピン長5.84mm。接触位置、底付き、公差は未実測。
支持スペーサーを先に無理に11mmで固定せず、完全嵌合した実高さにワッシャー等で合わせる。
基板厚1.6mmを両方のモデルに用いる。

音源基板の支持穴(mm)は(4,4)、(96,4)、(94,94)、(4,96)。ベース側は各点へ(90,38)を加えた位置。
非対称配置で回転を抑え、32番KEYも併用する。先に支持ガイドを合わせて行ずれを防ぐ。
音源基板の32番雄ピンを実装せず、雌側32番穴を塞ぐ。

ベース上で音源基板と重なる領域の部品高さを3mm以内、音源裏面の端子・はんだ突出も3mm以内とする。
対向面間を保守的に10.5mmとしても、部品と端子の間に4.5mmが残る。
ベースのPGA、USB・電源コネクタ、電解コンデンサ、LED、ボタンはこの領域外に置いた。

UNO R3接点座標は旧版と同じ。予約領域(7,7)..(83,67)mmに対し、音源基板はx90mmからで7mm離れる。
UNO雌ヘッダー8.51mm、シールド下面突出5mm以内なら3.51mmの隙間。
シールド基板の通常外形は(10,10)..(78.58,63.34)mm。任意のシールドの張出しは別確認。
UNO用穴H9/H10/H12で支持し、**H11はヘッダー端に近いため穴のみ・ネジ／スペーサーなし**。
ICSPは雄2×3。シールド側の雌SPIコネクタとの挿入・高さを実物で確認する。
ベース裏面と筐体・台座の間には8mm以上を取り、端子を切り揃える。

## 残る5か所のSMTビア

狭ピッチ部の引き出しで、音源基板の次のビア穴がSMTパッド内または近傍に残る。
自動検査は穴外周に50µmの余裕を加えて抽出する。ベース側の該当箇所は0。

|ref / pad|ネット|ビア中心(mm)|穴径(mm)|
|---|---|---|---:|
|ULINK1 /9|GND|(20.0625,52.3000)|0.30|
|ULINK1 /12|GND|(20.0625,50.3500)|0.30|
|ULINK0 /4|GND|(13.3375,38.0000)|0.30|
|U8 /3|YM_D0|(51.1500,54.7000)|0.20|
|U8 /10|YM_D7|(51.1375,59.2750)|0.20|

裏面テントを指定する。ICを載せる前に少量のはんだで穴を先埋めし、吸取線でパッドを平坦にして、
顕微鏡・拡大鏡で高さとブリッジを確認する。穴が開いたままICを載せると、はんだを吸い込んで接合不良を起こし得る。
先埋めが難しい場合は製造側の充填・銅蓋処理、または次版での引き出し変更が必要になる。
この処理を通常のDRCで検出できるとは扱わない。詳細位置は`hand-assembly-vias.json`。

## 初回の通電確認

Cの電源順序・ADC入力保護を維持する。5V/GND短絡、32番キー、3V3出力同士の非接続を確認してから電源を入れる。
最初はMCUとYMを外し、各レールとRUN/RESET/ゲートの既定状態を確認する。
実装後は負荷中のYM21番を4.75..5.25Vで確認し、レギュレーター・PTC・コネクタの温度を測定する。
Core FPC USBアダプターのVBUSと音源5Vを同時に給電しない。
停止・再接続時の無音、ADC電源OFF250ms後の0.1V未満、入力過渡と音量バランスは実機確認項目。
