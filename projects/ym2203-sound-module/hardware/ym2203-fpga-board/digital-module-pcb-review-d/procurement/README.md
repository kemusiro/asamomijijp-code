# P2 分離基板 review D 購入用部品表

2026-11-16時点。対象は `3.1-pcb-review-d` のベース1枚と、YM2203C×1音源基板1枚。
過去のRev C、FPGA案、F1、P1、一体型P2の購入表とは区別する。

`purchasing-bom.csv` は80品目、`implementation-map.csv` は回路BOM292参照
（ベース147、音源145）との対応表。ソケット・基板外部材を含めている。
`catalog.json` を数量・選定情報の正本とし、Excelはローカルのignored outputsへ出力する。

型番・必要数・購入先をブラウザで読む場合は[購入一覧](purchasing-table.md)を使用する。

## 購入表の使い方

- 1セット分と5セット分を併記。今回の発注枚数は未指定なので、Excel初期値は1セット。
- Excelの製作セット数、手持ち、予備、包装数を入力すると、発注単位と購入数量を計算する。
- `発注単位 = ceil(max(0, 必要数 × セット数 − 手持ち + 予備) / 包装数)`。
  数量の単位は原則個。J03だけ接点数で管理し、40接点のヘッダー何本を買うかへ丸める。
- 予備・手持ちの初期値は0。J03は最小4本/セットだが、切断・樹脂除去作業の予備を含め
  初回は5本が目安。5セットの19本は接点を全て回収した理論最少で、加工ロス分は追加する。
- `pack_verified=false` の包装数1は仮置き。メーカーのフルリール数を少量販売単位と
  誤認しないよう、カットテープ/バルクの最小発注数・倍数を購入画面で確認して変更する。
- `販売中を確認` はページ閲覧時点の表示。検索リンクの品目は型番を入力済みの検索であり、
  その店の在庫・納期・小口販売を確認したことを意味しない。価格・税・送料の総額見積ではない。
- `akizuki-order.csv` は秋月15品目を抜き出した手入力用一覧。サイト固有のインポート形式ではない。
  商品によって袋数/個数の入力欄が違うため、`packs_one` / `packs_five` を参照する。

## 発注前に合わせるもの

1. **YM2203C**は手持ち転用を第一候補とする。新品販売先は今回未確定。
   YM2203Cを所有済みならExcelの手持ちを1にする。追加購入品の真贋・動作は未確認。
2. **MCU用独立レセプタクル128個**はMill-Max指定品。0.64mm角ピンを受ける品であり、
   丸ピンICソケット用の細い穴では代替できない。少数でPCB穴・挿入深さ・モジュール高さを
   合わせてから残数を購入する。MCU側のオス128接点もJ03に含めた。
   MCUを囲う樹脂ヘッダーの四隅が干渉するため、樹脂除去・高さ治具が必要。
3. **基板間JMOD**はSSW-116-02-G-DとTSW-116-07-G-Dの組合せ。
   音源基板側オスは裏面。pin32はソケットを塞ぎ、オスを抜く。
   基板面間11.05mmは公称値なので、絶縁スペーサー/ワッシャーを実際の嵌合へ合わせる。
4. **USBコネクタとDIPスイッチ**は外形・取付穴が一致する品だけを発注する。
   USB-CはHRO TYPE-C-31-M-12用。DIPはKiCadが参照するCTS209系候補を挙げた。
   EDS104SZ等、ピッチだけ一致して本体幅が違う品を未確認で置換しない。
5. **外部電源・配線・取付部材**は仕様を示した選定待ち行。
   電源は5.1V級2A以上、負荷時のYM電源端子4.75～5.25Vを実測し、無負荷でも5.25Vを超えないこと。
   USB-C VBUSは検出用で、この基板の給電源ではない。
   JPOWERは2.54mmヘッダーで、一般的なDCジャックをPCBへ直接実装する設計ではない。
   電源側変換・極性・2A対応配線を選んでから購入する。
6. **Core2350B0-Kit**のUSBアダプター/FFCは初回書込み用としてセットに含めた。
   CoreのUSBアダプターと基板の外部5Vを同時に電源接続しない。
   UNOシールドの支柱は使用するシールドに合わせる。H11はねじなし、下面突出5mm以下。

この購入表はレビューDの部品を具体化したもの。PCB製造可否、実装嵌合、電源・音声、
P2用ファームウェアの実機受入は未完了で、Rev Cでの受入結果をP2の検証済みと扱わない。

## 置換を避ける品目

- 受動部品は **0805インチ=2012メートル**。秋月で多い1608メートル(0603インチ)へ変えない。
- TLV75533の入出力4.7µFは、3.3V/5V DCバイアス後に実効容量1µF以上を満たすことを確認する。
- 電源用MLCCはX7R、フィルターはC0G/NP0。廃番の秋月117576/115331/111622は発注先にしない。
- BAT54**S**は直列2素子。BAT54A/Cへ置換しない。
- SN74**LV4T125**とSN74LVC8T245は設計で選んだ電圧変換品。単純なHC/LVC125は不可。
- アナログスイッチはCD74**HC**4053M。旧検討用CD4053BM96は使わない。
- PCM1863/PCM5102A/Si5351AはIC単体用のPCB。秋月のDIP化モジュール・キットは実装できない。
- FM/SSGの表示LED7個は購入品を緑に統一。無極性電解4.7µFは通常の極性付き品へ置換しない。
- 小型タクトはSKHH**AL**A010（高さ4.3mm）。SKHH**AR**A010（高さ5mm）、
  秋月108215（二本足）・107193（高型）は今回の指定品に含めない。
- はんだジャンパー3件とテストパッド5件は銅箔のみ。独立したスイッチやチェック端子は買わない。

## 検証

```sh
python3 procurement/verify.py
```

このディレクトリの親（review D）から実行。回路BOMのハッシュ、292参照の対応漏れ・重複、
主要品目の独立集計、1/5セットの包装丸め、CSVの整合を確認する。
回路/PCB・ピン割当・ファームウェア・既存HOSTプロトコルは変更していない。
