購入資料review Dの候補であり、B/CのMPN、CAD、ネットリスト、GPIOを変更しない。旧行と購入材料の対応はpurchase-plan.jsonのcoversで維持する。

メーカー仕様は両方2.0±0.2 ×1.25±0.2 ×0.78±0.10 mm（高さ最大0.88 mm）、Sn終端。既存の0805を維持する寸法候補。メーカーの4000個リール数は小売CTのMOQではない。

一次仕様：[C0805C104K5RACTU](https://search.kemet.com/download/specsheet/C0805C104K5RACTU)、[C0805C222J5GACTU](https://search.kemet.com/download/specsheet/C0805C222J5GACTU)。

C01の28箇所はBのreference-mapを正本とする。C01はデカップリング、C09はADC周辺のフィルター用途。容量だけでなく誘電体・許容差・電圧・パッケージを維持した。新候補の実装確認・アナログ測定を行った記録ではない。ADC結合用C14のDC＋小AC条件・容量選別・未実測条件は変更しない。

## 機構部材

H05は内径3/外径7 mmのBRB003007100（t=1）、005（t=0.05）、010（t=0.1）を各7枚。各位置で1 mm本体＋必要な薄板を現物選択する。すべて重ねる指示ではない。M3ねじの実径、穴への通り、外径7 mmの周辺クリアランス、必要高さ、絶縁の必要箇所を現物確認する。

[モノタロウのメーカー型番別販売表](https://www.monotaro.com/g/00492582/)で1枚197円・107円・142円（税込）を確認。調整薄板を両厚さ用意する保守的な材料予算であり、装着部品点数を増やす設計変更ではない。

H06はSamtec PK-01-06。[Samtec資料（RS掲載）](https://docs.rs-online.com/fa99/A700000006774143.pdf)にSSW対応・6個wheelの記載があり、[DigiKey](https://www.digikey.jp/ja/products/detail/samtec-inc/PK-01-06/2058553)でMOQ1販売商品109円税別。SKU販売個を1栓と断定せず、必要KEY6の1箇所に使い、余栓数は受取時確認する。キーを塞ぐソケットの実穴・ヘッダー欠番との組合せは組立前に確認する。

## ハーネスを共用材料へ分解

電源・音量・HOSTの完成ハーネスE09/E10/E11を無根拠な完成品価格にせず、次を共同購入する。自作作業費・工具代は含めない。

- 秋月AWG22×10色各1 mセット（111641）520円。QIメス接点2226TX（112160）はAWG22–28・3 A、10個袋60円を2袋。必要17接点＝電源2＋音量/LINE9＋HOST6、余3。
- QIハウジング2P（112151）・6P（112155）・3P（112152）・4P（112153）各1、1P（112150）×3。電源用DCジャック端子台JR-56（108851）×1、収縮チューブ（131355）×1。
- 秋月KP01-06N-a 1芯シールド線3 m（113011）580円×1。音量入力/ワイパーL/RとLINE L/Rに計6本、各約25 cmの材料割当。編組が接点へ太すぎる場合は短いAWG22ピッグテールを使い、絶縁する。必要長は組立時に調整する。

実PCBの端子名を確認した接続表（ケーブル完成・導通検査済みという意味ではない）：

| コネクタ | 端子順 |
| --- | --- |
| JPOWER | 1 EXT5_IN / 2 GND |
| JHOST | 1 GND / 2 HOST_SDA / 3 HOST_SCL / 4 GND |
| JLINE | 1 LINE_L / 2 GND / 3 LINE_R |
| JPOT | 1 GND / 2 VOL_L / 3 LINE_FILTER_L / 4 GND / 5 VOL_R / 6 LINE_FILTER_R |

JHOSTの4番は追加GNDであり電源端子ではない。既存HOSTはPico GP0=SDA、GP1=SCL、GNDの3線、4番は未使用でよい。電源2線は短く（目安15 cm）、DCアダプターの極性と両端子をテスターで確認してから接続する。電源・信号ケーブルの見た目による取り違えを避ける。

メーカー・販売店一次ページへの各リンクと価格、MOQ、材質単位はpurchase-plan.json。販売店が接点の圧着またははんだ付けを案内しているため、特定の高価な圧着工具を必須購入品として追加していない。工具、はんだ、フラックス、ケース、PC、操作側Pico、microSD等は今回の部品BOM外。
